Реализованные требования для зачёта

Ниже представлен список требований

1.1. Семантическая разметка HTML5

Использовано более 5 семантических элементов:

  • <header> - шапка сайта
  • <main> - основное содержимое
  • <section> - секции портфолио и контактов
  • <article> - проекты и внутренние страницы
  • <footer> - подвал сайта
  • <nav> - навигация (неявно через ссылки)

1.2. Новые правила CSS3

Применено более 5 новых правил CSS3:

  • border-radius - скругления углов
  • flexbox - современная вёрстка
  • transition - плавные анимации
  • @media - адаптивный дизайн
  • object-fit - работа с изображениями
  • scroll-behavior: smooth - плавная прокрутка

1.3. Элементы управления форм HTML5

Использовано более 5 новых элементов управления:

  • type="email" - поле для email
  • type="tel" - поле для телефона
  • type="url" - поле для веб-сайта
  • type="range" - ползунок для оценки
  • placeholder - подсказки в полях
  • required - обязательные поля
  • pattern - валидация по шаблону

1.4. WebStorage (localStorage)

Реализовано хранение данных в браузере:

  • Сохранение даты последнего визита
  • Подсчёт количества посещений сайта
  • Вывод информации в консоль браузера
// Сохраняем дату последнего визита
localStorage.setItem('gfdf76g68dfg65df6', new Date().toISOString());

// Счетчик посещений
const visits = parseInt(localStorage.getItem('4fg3fd35gdfg54df5') || '0') + 1;
localStorage.setItem('4fg3fd35gdfg54df5', visits);

// Вывод в консоль для проверки
console.log(`Вы посетили сайт ${visits} раз`);
